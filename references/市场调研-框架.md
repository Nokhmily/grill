# 市场调研框架

本文件包含市场调研模式的完整框架。**主文件 `skill.md` 只引用本文件。**

---

## 目标用户画像（从代码功能反推）

- 从产品的技术复杂度推断：目标用户的技术水平（用 API → 开发者，拖拽界面 → 非技术用户）
- 从产品的功能深度推断：是轻量工具还是专业工具
- 从产品的使用流程推断：高频使用还是低频使用

---

## 竞品深度拷打（4 步）

### 第一步：竞品发现（联网搜索）

使用 WebSearch 搜索竞品，搜索策略：

| 搜索目标 | 搜索关键词 | 优先来源 |
|---------|-----------|---------|
| 直接竞品 | `"[核心功能]" alternatives` | Product Hunt、G2、Capterra |
| 同类产品 | `"[核心功能]" tool OR app` | Google、Bing |
| 开源替代 | `"[核心功能]" open source` | GitHub |
| 垂直竞品 | `"[行业]" + "[核心功能]"` | 行业网站 |
| 国内竞品 | `"[核心功能]" 国内 工具` | 知乎、少数派 |

### 第二步：竞品深度对比（逐项拷打）

| 对比维度 | 本产品 | 竞品 | 谁赢 | 为什么 |
|---------|--------|------|------|--------|
| 核心功能 | [代码中的实现] | [搜索到的信息] | [谁] | [原因] |
| 功能完整度 | [有/缺什么] | [有/缺什么] | [谁] | [差距] |
| 用户体验 | [从代码推断] | [从评价推断] | [谁] | [差异] |
| 上手门槛 | [几步能开始用] | [几步能开始用] | [谁] | [原因] |
| 定价 | [免费/付费] | [多少钱] | [谁] | [值不值] |
| 技术架构 | [代码中的栈] | [公开信息] | [谁] | [差异] |

### 第三步：SWOT 拷打

```
💪 优势 — 本产品有但竞品没有的
😰 劣势 — 本产品没有但竞品有的
🔮 机会 — 市场上还没人做好的
⚠️ 威胁 — 竞品可能抄过来的
```

### 第四步：差异化拷打（5 个灵魂拷问）

1. **"如果竞品抄了你的核心功能，你还剩什么？"**
2. **"用户为什么不用竞品而来用你？"**
3. **"你的产品有什么是竞品做不了的？"**
4. **"竞品的用户最吐槽什么？你解决了吗？"**
5. **"如果明天竞品免费了，你还活吗？"**

## 市场空间评估

- 这个品类的市场有多大？（大致估算）
- 是增量市场还是存量市场？
- 进入门槛如何？

## 定价参考

- 类似产品通常怎么收费？
- 这个产品适合什么定价模式？（免费/Freemium/订阅/一次性付费）
- 用户的付费意愿如何？

## 输出格式

```
📊 市场调研报告

👤 目标用户画像
- 核心用户：[描述]
- 用户痛点：[什么问题让他们寻找解决方案]

🏆 竞品发现
| 竞品 | 核心功能 | 定价 | 目标用户 |
|------|---------|------|---------|

⚔️ 逐项对比
| 维度 | 本产品 | 竞品1 | 竞品2 | 谁赢 |
|------|--------|-------|-------|------|

📋 SWOT 分析
🎯 差异化拷打（5 个灵魂拷问的回答）
📈 市场评估 + 💰 定价建议
```
