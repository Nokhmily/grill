# grill - 产品拷打器

一个 Claude Code skill，从用户视角拷打你的 vibe coding 产品——发现问题、挖掘场景、模拟反馈、帮你完善产品。

## ✨ 功能特性

- 🎯 **智能产品分类** — 自动识别 10 种产品类型，只拷打相关的维度
- 📐 **复杂度自适应** — 根据项目大小自动调整拷打深度（轻量/标准/深度）
- 🔍 **8+2 个场景施压** — 从首次见到多端入口，覆盖用户使用的全流程
- 🔬 **6 个拷打透镜** — 技术风险、商业模式、数据流、合规、增长、运维
- 🧠 **4 种深度拷问** — 5 Whys、反事实推演、极端用户画像、MVP 逆向拆解
- 👥 **5 个证人交叉质询** — 小白用户、目标用户、竞品用户、付费用户、路演观众
- 🏥 **行业视角** — 医学、金融、法律、教育、设计、工程 6 大行业深度场景
- ⚡ **快速拷打模式** — 轻量项目 30 秒出结果
- 📋 **输出分层** — 摘要+详细两层输出，按需展开

## 🚀 安装

```bash
# 方式 1：克隆到 Claude Code skills 目录
git clone https://github.com/Nokhmily/grill.git ~/.claude/skills/grill

# 方式 2：使用 npx skills（如果支持）
npx skills add Nokhmily/grill
```

## 📖 使用

```bash
# 拷打本地项目
/grill /path/to/your/project

# 拷打 GitHub 仓库
/grill https://github.com/user/repo

# 交互式选择项目
/grill
```

## 📐 拷打流程

```
代码分析 → 复杂度评估 → 产品分类 → 选择拷打角度 → 多维度分析 → 交叉质询 → 去重合并 → 宣判
```

### 复杂度自适应

| 等级 | 条件 | 深度 | 输出 |
|------|------|------|------|
| 🟢 轻量 | <30 文件 | 3 场景 + 2 证人 | 500 字，30 秒 |
| 🟡 标准 | 30-150 文件 | 6 场景 + 3 证人 | 1500 字 |
| 🔴 深度 | >150 文件 | 全部场景 + 证人 + 透镜 | 完整报告 |

### 产品类型自动识别

支持 10 种产品类型：个人项目、开源项目、SaaS、电商、移动应用、内容平台、企业工具、AI/ML、开发者工具、教育产品。

每种类型自动匹配相关的拷打角度，不相关的自动跳过。

### 拷打透镜（可叠加）

| 透镜 | 核心问题 |
|------|---------|
| 🔬 技术风险 | 代码里埋了多少雷？ |
| 💰 商业拷打 | 这东西怎么赚钱？ |
| 🔄 数据流 | 数据从哪来，到哪去？ |
| ♿ 合规无障碍 | 特殊用户能用吗？合法吗？ |
| 🚀 增长路径 | 用户怎么来，怎么留？ |
| 🖥️ 运维部署 | 上线后能活多久？ |

## 📋 输出示例

### 快速拷打（轻量项目）

```
⚡ 快速拷打结果

🏆 Top 3 问题：
1. 🔴 首页没有引导文案 — index.html:15 → 加一句"点击 + 开始创建"
2. 🟡 搜索没有防抖 — app.js:42 → 加 300ms debounce
3. 🟡 删除没有确认弹窗 — app.js:67 → 加 confirm() 或回收站

```
